Privacy policy

This policy describes the current owner-operated IdeaCircuit Studio workflow. There is no public user registration or public authorization flow on this site.

Google and YouTube data

The owner authorizes access to their own YouTube channel using Google OAuth. The workflow uses channel identifiers and names, uploaded video identifiers, video titles and descriptions, tags, privacy settings, processing status and scheduled release times. Video files and their publishing metadata are sent to YouTube when the owner requests an upload.

OAuth credentials allow the workflow to refresh access and perform authorized YouTube operations. They are kept in operator-controlled credential stores, including encrypted GitHub Actions secrets. Access tokens are used during execution and are not included in published pages or upload receipts.

How the data is used and shared

Data is used to produce the owner’s videos, verify the intended channel, upload or schedule videos, check processing and avoid duplicate uploads. Google and YouTube process the media and account operations. GitHub hosts the workflow, its private source repository, run artifacts and publishing records. The workflow does not sell Google user data or use it for advertising.

IdeaCircuit Studio’s use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Storage and retention

Credentials remain in the operator’s credential stores until replaced or removed. The current GitHub workflow retains rendered review artifacts for seven days and publishing receipt artifacts for thirty days. The private upload ledger remains until the operator removes it. Videos and metadata uploaded to YouTube remain there until changed or deleted through YouTube.

Control, revocation and deletion

The owner can revoke the application’s Google authorization through Google Account connections, remove the GitHub Actions secret, and delete private workflow records or artifacts. Revoking authorization does not automatically delete videos already uploaded to YouTube; those can be managed in YouTube Studio.

This website

This static information site has no forms, custom tracking scripts or advertising. GitHub Pages hosts the site and may process visitor IP addresses and other request information for hosting and security under the GitHub Privacy Statement.

Operator and privacy requests

The application is maintained by the owner of The Idea Circuit. It is used only with that owner’s account. The owner controls removal of the credentials, workflow records and uploaded content described above.
